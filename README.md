# Bora Lá — demonstração

App do público (protótipo navegável): mapa de calor da noite carioca com o Vibemetro.

- **Real:** geografia e polígonos dos 166 bairros (IPP/Data.Rio, CC-BY), nomes e coordenadas de lugares (OpenStreetMap, ODbL), fórmulas do Vibemetro v3.
- **Simulado:** avaliações, engajamento, horários dos eventos, parças, listas, reviews e feed (semente fixa).
- Nenhum dado seu sai do aparelho: tudo fica no `localStorage`.

Fonte: https://github.com/IagoAlfiro/BoraLa (pasta `demo/app`).
